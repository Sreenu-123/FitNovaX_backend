# 💪 FitNovaX Backend

### Powering the Future of Fitness.

**FitNovaX Backend** is the server-side component of FitNovaX, a fitness and wellness application built with FastAPI and PostgreSQL.

> 🚧 **STATUS: WORK IN PROGRESS**
>
> The backend is actively under development. Features, APIs, and functionality may change as the project evolves.

---

## ✨ About

FitNovaX Backend provides the foundation for the FitNovaX mobile application by handling authentication, user profile management, password recovery, and database operations.

Built with FastAPI and PostgreSQL, the backend is being developed to support a reliable and scalable fitness platform.

## 🛠️ Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- REST API
- PBKDF2-based password hashing
- Resend for email delivery

## ⚙️ Core Functionality

- 🔐 User registration and authentication
- 👤 User profile management
- 🔑 Password recovery
- 🗄️ PostgreSQL database integration
- 📡 REST API endpoints for mobile app communication
- ✉️ Email delivery integration

*Some functionality is still under development and may change as development progresses.*
